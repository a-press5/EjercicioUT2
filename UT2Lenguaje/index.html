Grado superior de desarrollo de aplicaciones web

DAW es un ciclo formativo de grado superior

Primer curso

En el primer curso se estudian las bases de la programación, bases de datos, desarrollo web y sistemas informáticos.

Segundo curso

En el segundo curso se profundiza en el desarrollo web, programación avanzada, administración de sistemas y desarrollo de aplicaciones multiplataforma.

Salidas profesionales

  1. Desarrollador web
  2. Administrador de sistemas
  3. Desarrollador de aplicaciones móviles
  4. Analista programador
